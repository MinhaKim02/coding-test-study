# K번째수

`Lv.1` · `정렬` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42748)

> 해설 보고 공부

## 핵심 아이디어

i번째~j번째 자르기 → 정렬 → k번째. 문제는 1부터, 파이썬 인덱스는 0부터.

## 실수 / 배운 점

- 'i번째부터 j번째까지' → `a[i-1:j]` (끝은 j 그대로)
- `a.sort()`는 원본 정렬(None 반환), `sorted(a)`는 새 리스트

## 정리한 풀이

```python
def solution(array, commands):
    answer = []
    for i, j, k in commands:
        part = sorted(array[i-1:j])
        answer.append(part[k-1])
    return answer
```
