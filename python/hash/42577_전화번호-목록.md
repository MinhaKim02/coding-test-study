## 핵심 아이디어

번호가 최대 100만 개라 이중 for문 비교는 시간 초과. 방향을 뒤집어서 '내 번호의 앞부분들이 전화번호부(set)에 있나?'를 확인한다. 번호 길이 ≤ 20이라 빠르다.

## 내 풀이

```python
def solution(phone_book):
    s = set(phone_book)
    for num in phone_book:
        for i in range(1, len(num)):
            if num[:i] in s:
                return false
    return true
```

## 실수 / 배운 점

- `false`/`true` → `False`/`True` (파이썬은 대문자)
- 'A가 B의 접두어' = 긴 쪽 B를 자르고(`B[:i]`), 짧은 쪽 A는 통째로 비교
- `range(1, len(num))` → 자기 자신 전체는 제외
- range·슬라이싱은 시작 포함, 끝 미포함

## 정리한 풀이

```python
def solution(phone_book):
    s = set(phone_book)
    for num in phone_book:
        for i in range(1, len(num)):
            if num[:i] in s:
                return False
    return True

# 정렬 풀이: 정렬하면 접두어 관계는 바로 옆에 붙는다
def solution2(phone_book):
    phone_book.sort()
    for a, b in zip(phone_book, phone_book[1:]):
        if b.startswith(a):
            return False
    return True
```
