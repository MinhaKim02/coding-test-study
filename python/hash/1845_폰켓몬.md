## 핵심 아이디어

고를 수 있는 수(N/2)와 종류 수(len(set)) 중 작은 값.

## 실수 / 배운 점

- `{}`는 빈 dict, 빈 set은 `set()`
- 변수 이름으로 `set`, `list`, `sum` 쓰지 않기 (내장 함수가 덮어써짐)
- 정수 나눗셈은 `//`

## 정리한 풀이

```python
def solution(nums):
    return min(len(set(nums)), len(nums) // 2)
```
