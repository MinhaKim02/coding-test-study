# 베스트앨범

## 핵심 아이디어

① 장르별 총 재생 수 ② 장르별 (재생수, 번호) 목록 ③ 총 재생 수 큰 장르부터 ④ 장르 안에서 재생수↓, 번호↑ 정렬 후 2개.

## 내 풀이

```python
def solution(genres, plays):
    d = {}
    for i in range(0, len(genres)):
        d[genres[i]] = d.get(genres[i], 0) + plays[i]
    # (여기까지 직접 작성)
```

## 실수 / 배운 점

- `sorted(d, key=lambda x: -d[x])` → dict 키를 값 기준 내림차순
- `key=lambda x: (-x[0], x[1])` → 1순위 내림, 2순위 오름
- `setdefault` 대신 if로 리스트 만들어도 됨

## 정리한 풀이

```python
def solution(genres, plays):
    total = {}
    songs = {}
    for i in range(len(genres)):
        g = genres[i]
        total[g] = total.get(g, 0) + plays[i]
        if g not in songs:
            songs[g] = []
        songs[g].append((plays[i], i))

    answer = []
    for g in sorted(total, key=lambda x: -total[x]):
        top = sorted(songs[g], key=lambda x: (-x[0], x[1]))[:2]
        for p, i in top:
            answer.append(i)
    return answer
```
