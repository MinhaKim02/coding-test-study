## 핵심 아이디어

종류별 개수를 센 뒤, 각 종류마다 '안 입는' 선택지를 더해 곱한다. 전부 안 입는 경우 1을 뺀다: ∏(개수 + 1) − 1.

## 실수 / 배운 점

- `for name, kind in clothes:` → 2칸짜리 리스트 나눠 받기
- `d.values()` 값만 / `d.keys()` 키만 / `d.items()` 둘 다
- 곱셈 누적은 1부터, 덧셈 누적은 0부터

## 정리한 풀이

```python
def solution(clothes):
    d = {}
    for name, kind in clothes:
        d[kind] = d.get(kind, 0) + 1

    answer = 1
    for cnt in d.values():
        answer *= (cnt + 1)
    return answer - 1
```
