# 타겟 넘버

`Lv.2` · `DFS/BFS` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/43165)

> 템플릿으로 공부

## 핵심 아이디어

숫자마다 +/− 두 갈래로 끝까지 가서(DFS 재귀) 합이 target이면 1, 아니면 0. 두 갈래 결과를 더하면 전체 경우의 수.

## 실수 / 배운 점

- `return`은 프로그램 종료가 아니라 나를 호출한 자리로 값을 들고 돌아가기
- `idx == len(numbers)`는 '다 썼다'는 끝 신호 — 인덱스 접근은 그 검사 뒤에
- 들여쓰기 = 소속. 바깥 if가 거짓이면 안쪽은 통째로 건너뜀
- `A if 조건 else B` = if/else 4줄과 같음

## 정리한 풀이

```python
def solution(numbers, target):
    def dfs(idx, total):
        if idx == len(numbers):          # 숫자를 다 썼으면 판정
            if total == target:
                return 1
            else:
                return 0
        return (dfs(idx + 1, total + numbers[idx])     # + 갈래
              + dfs(idx + 1, total - numbers[idx]))    # − 갈래
    return dfs(0, 0)
```
