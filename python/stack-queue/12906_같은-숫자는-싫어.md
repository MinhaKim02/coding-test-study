# 같은 숫자는 싫어

`Lv.1` · `스택/큐` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12906)

> 직접 풂

## 핵심 아이디어

스택 맨 위(마지막으로 넣은 값)와 다를 때만 넣는다. 한 번 훑으므로 O(n).

## 내 풀이

```python
def solution(arr):
    answer = []
    num = arr[0]
    answer.append(arr[0])
    for i in range(1, len(arr)):
        if arr[i] != num:
            answer.append(arr[i])
            num = arr[i]

    return answer
```

## 실수 / 배운 점

- `a[-1]` = 마지막 값(스택 맨 위) → 따로 변수 둘 필요 없음
- 인덱스를 덜 쓸수록 IndexError가 줄어든다

## 정리한 풀이

```python
def solution(arr):
    answer = []
    for x in arr:
        if not answer or answer[-1] != x:
            answer.append(x)
    return answer
```
