# 문자열 반복해서 출력하기

`Lv.0` · `코딩 기초 트레이닝` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181950)

## 핵심 아이디어

문자열 str을 n번 이어서 출력. 자바는 `문자열 * 숫자`가 안 되므로 for문 또는 `repeat`.

## 내 풀이

```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String str = sc.next();
        int n = sc.nextInt();

        for (int i = 0; i < n; i++) {
            System.out.print(str);
        }
    }
}
```

## 실수 / 배운 점

- 처음엔 파이썬처럼 곱하기를 시도 → 자바는 문자열 × 숫자 ❌
- `for (int i = 0; i < n; i++)` = 파이썬 `for i in range(n)` (C/C++과 같은 문법)
- 이어서 출력할 땐 `print`, 줄바꿈이 필요할 때만 `println`

## 정리한 풀이

```java
System.out.println(str.repeat(n));   // Java 11+
```
