# 대소문자 바꿔서 출력하기

`Lv.0` · `코딩 기초 트레이닝` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181949)

## 핵심 아이디어

문자열을 한 글자씩 꺼내서 대문자면 소문자로, 소문자면 대문자로 바꿔 이어서 출력.

## 내 풀이

```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String a = sc.next();

        for (int i = 0; i < a.length(); i++) {
            if (Character.isUpperCase(a.charAt(i))) {
                System.out.print(Character.toLowerCase(a.charAt(i)));
            } else {
                System.out.print(Character.toUpperCase(a.charAt(i)));
            }
        }
    }
}
```

## 실수 / 배운 점

첫 시도에서 틀린 것 (파이썬·C++ 습관):

- `for (i = 0; …)` → for문 변수도 타입 필수 `int i`
- 입력 변수는 `a`인데 `str`을 사용 → "cannot find symbol"
- `str[i]` ❌ → 자바 문자열은 `a.charAt(i)`
- `Chracter` 오타 → `Character`

새로 배운 문법:

- `s.length()` 문자열 길이 (괄호 있음), `s.charAt(i)` i번째 글자 (`char`)
- `Character.isUpperCase(c)`, `Character.toLowerCase(c)`, `Character.toUpperCase(c)`

## 정리한 풀이

```java
for (int i = 0; i < a.length(); i++) {
    char c = a.charAt(i);   // 한 번 꺼내두면 반복·오타가 줄어든다
    if (Character.isUpperCase(c)) {
        System.out.print(Character.toLowerCase(c));
    } else {
        System.out.print(Character.toUpperCase(c));
    }
}
```
