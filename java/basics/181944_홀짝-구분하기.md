# 홀짝 구분하기

`Lv.0` · `코딩 기초 트레이닝` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181944)

> Java 첫 문제

## 핵심 아이디어

정수 n을 입력받아 `n % 2 == 0`이면 `n is even`, 아니면 `n is odd`를 출력한다. `solution` 함수가 아니라 입력·출력을 직접 하는 형식.

## 내 풀이

```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        if (n % 2 == 0) {
            System.out.println(n + " is even");
        } else {
            System.out.println(n + " is odd");
        }
    }
}
```

## 실수 / 배운 점 (Python과 다른 점)

- 변수는 타입을 앞에: `int n = 3;`
- 줄 끝 `;` 필수, 블록은 `{ }`, `if ( )` 괄호 필수
- 출력 `System.out.println(...)` = 출력 후 줄바꿈 (`print`는 줄바꿈 없음)
- 입력 `Scanner sc = new Scanner(System.in);` → `sc.nextInt()` / `sc.next()` / `sc.nextLine()`
- 숫자 + 문자열은 `+`로 붙이면 문자열이 됨 (`n + " is even"`)
