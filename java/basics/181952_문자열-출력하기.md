# 문자열 출력하기

`Lv.0` · `코딩 기초 트레이닝` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181952)

## 핵심 아이디어

문자열 하나를 입력받아 그대로 출력.

## 내 풀이

```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String a = sc.next();

        System.out.println(a);
    }
}
```

## 실수 / 배운 점

- 문자열 입력은 `sc.next()` (공백 전까지 한 단어), 한 줄 전체는 `sc.nextLine()`
- 문자열 타입은 `String` (대문자 S)
