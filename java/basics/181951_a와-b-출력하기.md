# a와 b 출력하기

`Lv.0` · `코딩 기초 트레이닝` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181951)

## 핵심 아이디어

정수 두 개를 입력받아 `a = 값`, `b = 값` 형식으로 두 줄 출력.

## 내 풀이

```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();

        System.out.println("a = " + a);
        System.out.println("b = " + b);
    }
}
```

## 실수 / 배운 점

- `nextInt()`를 두 번 호출하면 공백이나 줄바꿈으로 구분된 정수를 차례대로 읽는다
- `"a = " + a` → 문자열 + 숫자 = 문자열
