# 특정 옵션이 포함된 자동차 리스트 구하기

`Lv.1` · `String, Date` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/157343)

## 핵심 아이디어

OPTIONS 문자열에 '네비게이션'이 포함된 차 = LIKE '%네비게이션%'.

## 내 풀이

```sql
select CAR_ID, CAR_TYPE, DAILY_FEE, OPTIONS
from car_rental_company_car
where options like '%네비게이션%'
order by car_id desc;
```

## 실수 / 배운 점

- `%`는 '아무 글자 0개 이상' → 앞뒤에 붙이면 '포함'
