# 조건에 맞는 도서와 저자 리스트 출력하기

`Lv.2` · `String, Date` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/144854)

## 핵심 아이디어

경제 카테고리 도서를 저자와 JOIN, 날짜 포맷을 예시와 동일하게.

## 내 풀이

```sql
SELECT BOOK_ID, AUTHOR_NAME, PUBLISHED_DATE
from book t1 join author t2 on t1.author_id = t2.author_id
where category = '경제'
order by published_date;
```

## 실수 / 배운 점

- '날짜 포맷 예시와 동일' → `DATE_FORMAT(col, '%Y-%m-%d')`
- `DATE()` = 시간 자르기(날짜 타입) / `DATE_FORMAT()` = 원하는 모양의 문자열

## 정리한 풀이

```sql
SELECT t1.BOOK_ID, t2.AUTHOR_NAME,
       DATE_FORMAT(t1.PUBLISHED_DATE, '%Y-%m-%d') AS PUBLISHED_DATE
FROM BOOK t1
JOIN AUTHOR t2 ON t1.AUTHOR_ID = t2.AUTHOR_ID
WHERE t1.CATEGORY = '경제'
ORDER BY t1.PUBLISHED_DATE;
```
