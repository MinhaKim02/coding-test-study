# 조건에 맞는 사용자와 총 거래금액 조회하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/164668)

## 핵심 아이디어

완료된 거래만 JOIN 후 사용자별 SUM, 70만 원 이상.

## 내 풀이

```sql
select USER_ID, NICKNAME, SUM(PRICE) as TOTAL_SALES
from used_goods_board t1 join used_goods_user t2
on t1.writer_id = t2.user_id
where status = 'DONE'
group by user_id
having sum(price) >= 700000
order by sum(price);
```

## 실수 / 배운 점

- SELECT의 일반 컬럼(NICKNAME)도 GROUP BY에 넣어두면 안전
