# 자동차 종류 별 특정 옵션이 포함된 자동차 수 구하기

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/151137)

## 핵심 아이디어

OPTIONS에 통풍시트·열선시트·가죽시트 중 하나라도 포함된 차를 종류별로 COUNT.

## 내 풀이

```sql
with cte as (SELECT *, case when options like '%통풍시트%' or options like '%열선시트%' or options like '%가죽시트%' then 1 else 0 end as cnt
from car_rental_company_car)
select CAR_TYPE, count(*) as CARS
from cte
where cnt = 1
group by car_type
order by car_type;
```

## 실수 / 배운 점

- 행 필터만 필요하면 CTE 없이 WHERE로 충분 (CTE는 단계가 필요할 때만)
- AND/OR을 섞으면 괄호 필수 (AND가 먼저 계산됨)

## 정리한 풀이

```sql
SELECT CAR_TYPE, COUNT(*) AS CARS
FROM CAR_RENTAL_COMPANY_CAR
WHERE OPTIONS REGEXP '통풍시트|열선시트|가죽시트'
GROUP BY CAR_TYPE
ORDER BY CAR_TYPE;
```
