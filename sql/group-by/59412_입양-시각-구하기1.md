# 입양 시각 구하기(1)

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/59412)

## 핵심 아이디어

09:00~19:59 사이 시간대별 COUNT.

## 내 풀이

```sql
SELECT hour(datetime) as HOUR, count(*) as COUNT
from animal_outs
where (hour(datetime) >= 9) and (hour(datetime) < 20)
group by hour(datetime)
order by hour(datetime);
```

## 실수 / 배운 점

- HOUR는 정수라 `BETWEEN 9 AND 19`도 같음 (BETWEEN은 양 끝 포함)

## 정리한 풀이

내 풀이 그대로 정답.
