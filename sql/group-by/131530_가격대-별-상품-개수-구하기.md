# 가격대 별 상품 개수 구하기

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131530)

## 핵심 아이디어

만 원 단위로 내림해서 가격대를 만들고 COUNT.

## 내 풀이

```sql
select floor(price / 10000) * 10000 as PRICE_GROUP, count(*) as PRODUCTS
from product
group by price_group
order by price_group;
```

## 실수 / 배운 점

- `unsign()`이라는 함수는 없다
- `CAST(… AS UNSIGNED)`는 반올림(1.9 → 2) → 구간 묶기는 FLOOR 또는 `TRUNCATE(PRICE, -4)`
