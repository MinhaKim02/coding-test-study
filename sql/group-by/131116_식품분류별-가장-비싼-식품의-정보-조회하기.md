# 식품분류별 가장 비싼 식품의 정보 조회하기

`Lv.4` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131116)

## 핵심 아이디어

그룹별 최댓값 행 찾기. 윈도우 함수로 카테고리별 MAX를 붙인 뒤 PRICE = MAX_PRICE로 거른다.

## 내 풀이

```sql
with cte (SELECT category, price, product_name,
          max(price) over (partition by category) as max_price
          from food_product)
select category, max_price, product_name
from cte
where price = max_price and category in ('과자', '국', '김치', '식용유')
order by max_price desc;
```

## 실수 / 배운 점

- `WITH cte (SELECT …)` → `AS` 누락. 프로그래머스는 'Only SELECT statements are allowed'로 표시됨 = 문법 오타부터 의심

## 정리한 풀이

```sql
-- 방법 ① 윈도우 함수
WITH cte AS (
    SELECT CATEGORY, PRICE, PRODUCT_NAME,
           MAX(PRICE) OVER (PARTITION BY CATEGORY) AS MAX_PRICE
    FROM FOOD_PRODUCT
    WHERE CATEGORY IN ('과자', '국', '김치', '식용유')
)
SELECT CATEGORY, MAX_PRICE, PRODUCT_NAME
FROM cte
WHERE PRICE = MAX_PRICE
ORDER BY MAX_PRICE DESC;

-- 방법 ② (그룹, 값) IN 서브쿼리
SELECT CATEGORY, PRICE AS MAX_PRICE, PRODUCT_NAME
FROM FOOD_PRODUCT
WHERE (CATEGORY, PRICE) IN (SELECT CATEGORY, MAX(PRICE)
                            FROM FOOD_PRODUCT
                            WHERE CATEGORY IN ('과자', '국', '김치', '식용유')
                            GROUP BY CATEGORY)
ORDER BY MAX_PRICE DESC;
```
