# 동명 동물 수 찾기

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/59041)

## 핵심 아이디어

이름이 있는 동물만 이름별 COUNT, 2번 이상인 것.

## 내 풀이

```sql
select NAME, count(*) as COUNT
from animal_ins
group by name
having count(*) >= 2 and name is not null
order by name;
```

## 실수 / 배운 점

- 일반 조건(IS NOT NULL)은 WHERE, 집계 조건(COUNT)은 HAVING

## 정리한 풀이

```sql
SELECT NAME, COUNT(*) AS COUNT
FROM ANIMAL_INS
WHERE NAME IS NOT NULL
GROUP BY NAME
HAVING COUNT(*) >= 2
ORDER BY NAME;
```
