# 월별 잡은 물고기 수 구하기

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/293260)

## 핵심 아이디어

월별 COUNT. 잡은 물고기가 없는 월은 출력하지 않으므로 숫자 테이블 불필요.

## 내 풀이

```sql
select count(*) as FISH_COUNT,
month(time) as MONTH
from fish_info
group by month(time)
order by month(time);
```

## 실수 / 배운 점

- '없는 것도 0으로 출력'이면 숫자 테이블 + LEFT JOIN, 아니면 GROUP BY만
