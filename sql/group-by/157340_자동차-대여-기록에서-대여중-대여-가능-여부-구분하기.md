# 자동차 대여 기록에서 대여중 / 대여 가능 여부 구분하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/157340)

## 핵심 아이디어

차 한 대에 대여 기록이 여러 줄이다. 기록 중 하나라도 2022-10-16에 걸리면 '대여중'. 조건을 1/0으로 바꾼 뒤 차별 MAX를 보면 '하나라도 있나?'를 알 수 있다.

## 내 풀이

```sql
SELECT CAR_ID,
CASE
    WHEN DATE(2022-10-16) BETWEEN (START_DATE, END_DATE)
    THEN "대여 중"
    ELSE "대여 가능"
END AS AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
ORDER BY CAR_ID DESC;
```

## 실수 / 배운 점

- `DATE(2022-10-16)`은 숫자 뺄셈(1996)이 된다 → 날짜는 `'2022-10-16'` 따옴표로
- `BETWEEN (A, B)` ❌ → `BETWEEN A AND B`
- 기록이 여러 줄이라 CAR_ID가 중복 출력됨 → `GROUP BY CAR_ID`
- 출력 문자열은 문제 그대로: `'대여중'`(붙여서), `'대여 가능'`(띄어서)

## 정리한 풀이

```sql
SELECT CAR_ID,
       CASE WHEN MAX(CASE WHEN '2022-10-16' BETWEEN START_DATE AND END_DATE
                          THEN 1 ELSE 0 END) = 1
            THEN '대여중' ELSE '대여 가능' END AS AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
ORDER BY CAR_ID DESC;
```
