# 성분으로 구분한 아이스크림 총 주문량

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/133026)

## 핵심 아이디어

FIRST_HALF와 ICECREAM_INFO를 FLAVOR로 JOIN하고 성분 타입별 SUM.

## 내 풀이

```sql
SELECT INGREDIENT_TYPE, SUM(TOTAL_ORDER) as TOTAL_ORDER
from first_half f join icecream_info i on f.flavor = i.flavor
group by ingredient_type
order by sum(TOTAL_ORDER);
```

## 실수 / 배운 점

- 별칭이 원래 컬럼명과 같을 때 ORDER BY에는 집계식 `SUM(...)`을 직접 → 애매함 없음 (잘한 점)
