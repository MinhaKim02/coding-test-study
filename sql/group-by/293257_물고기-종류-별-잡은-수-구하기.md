# 물고기 종류 별 잡은 수 구하기

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/293257)

## 핵심 아이디어

FISH_INFO와 FISH_NAME_INFO를 JOIN하고 이름별 COUNT.

## 내 풀이

```sql
select count(*) as FISH_COUNT, FISH_NAME
from fish_info t1 join fish_name_info t2 on t1.fish_type = t2.fish_type
group by fish_name
order by count(*) desc;
```

## 실수 / 배운 점

- 한쪽 테이블에만 있는 컬럼은 별칭 없이도 OK, 그래도 `t2.FISH_NAME` 습관
