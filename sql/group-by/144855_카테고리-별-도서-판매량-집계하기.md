# 카테고리 별 도서 판매량 집계하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/144855)

## 핵심 아이디어

BOOK과 BOOK_SALES를 JOIN, 2022년 1월만, 카테고리별 SUM.

## 내 풀이

```sql
select CATEGORY, sum(sales) as TOTAL_SALES
from book t1 join book_sales t2 on t1.book_id = t2.book_id
where sales_date >= '2022-01-01' and sales_date < '2022-02-01'
group by category
order by category;
```

## 실수 / 배운 점

- 월 필터 패턴 `>= 이번달 1일 AND < 다음달 1일`
