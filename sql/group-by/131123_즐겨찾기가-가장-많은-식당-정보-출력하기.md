# 즐겨찾기가 가장 많은 식당 정보 출력하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131123)

## 핵심 아이디어

음식 종류별 즐겨찾기 최댓값 행 찾기 (131116과 같은 패턴).

## 내 풀이

```sql
SELECT FOOD_TYPE, REST_ID, REST_NAME, FAVORITES
from (select food_type, rest_id, rest_name, favorites,
     max(favorites) over (partition by food_type) as max_fav
     from rest_info) r
where favorites = max_fav
order by food_type desc;
```

## 실수 / 배운 점

- FROM 서브쿼리(derived table)는 별칭 필수 `( … ) r` — 안 붙이면 'Every derived table must have its own alias'
- MAX() OVER로 거르면 동점이 다 나온다. 1개만 필요하면 `ROW_NUMBER() = 1`
- ROW_NUMBER 1-2-3 / RANK 1-1-3 / DENSE_RANK 1-1-2

## 정리한 풀이

내 풀이 그대로 정답.
