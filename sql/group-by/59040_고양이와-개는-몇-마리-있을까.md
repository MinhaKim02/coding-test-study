# 고양이와 개는 몇 마리 있을까

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/59040)

## 핵심 아이디어

동물 종류별 COUNT. 'Cat' < 'Dog'라 알파벳 정렬로 고양이가 먼저.

## 내 풀이

```sql
SELECT ANIMAL_TYPE, count(*) as count
from animal_ins
group by animal_type
order by animal_type;
```

## 실수 / 배운 점

- 원하는 순서로 정렬해야 하면 `ORDER BY FIELD(col, 'Dog', 'Cat')`

## 정리한 풀이

내 풀이 그대로 정답.
