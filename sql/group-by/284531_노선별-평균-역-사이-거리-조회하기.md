# 노선별 평균 역 사이 거리 조회하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/284531)

## 핵심 아이디어

노선별 SUM, AVG를 반올림해서 'km'를 붙인다. 단 정렬은 숫자로.

## 내 풀이

```sql
select ROUTE, concat(round(SUM(d_between_dist), 1), 'km') as TOTAL_DISTANCE,
concat(round(AVG(D_BETWEEN_DIST), 2), 'km') as AVERAGE_DISTANCE
from subway_distance
group by route
order by round(SUM(d_between_dist)) desc;
```

## 실수 / 배운 점

- MySQL에서 문자열 붙이기는 `CONCAT` (`+`는 숫자 덧셈)
- CAST 타입은 `CHAR`, `SIGNED` 등 (`string` ❌), 문법은 `CAST(x AS 타입)`
- 단위를 붙이면 문자열 → `ORDER BY 별칭`은 사전순('9.5km' > '10.2km') → 원래 숫자 식으로 정렬
- 정렬용 식에 ROUND를 걸면 동점이 생길 수 있음 → 반올림하지 않은 SUM으로

## 정리한 풀이

```sql
SELECT ROUTE,
       CONCAT(ROUND(SUM(D_BETWEEN_DIST), 1), 'km') AS TOTAL_DISTANCE,
       CONCAT(ROUND(AVG(D_BETWEEN_DIST), 2), 'km') AS AVERAGE_DISTANCE
FROM SUBWAY_DISTANCE
GROUP BY ROUTE
ORDER BY SUM(D_BETWEEN_DIST) DESC;
```
