# 연간 평가점수에 해당하는 평가 등급 및 성과금 조회하기

`Lv.4` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/284528)

## 핵심 아이디어

상·하반기 점수를 어떻게 합칠지 본문에 없다 → 예시 출력으로 역산하면 평균. 사원별 AVG(SCORE)로 등급과 성과금 비율을 CASE로.

## 내 풀이

```sql
select e.emp_no EMP_NO, EMP_NAME,
case
when avg(score) >= 96 then 'S'
when avg(score) >= 90 then 'A'
when avg(score) >= 80 then 'B'
else 'C'
end as GRADE,
sal * (case when avg(score) >= 96 then 0.2
when avg(score) >= 90 then 0.15
when avg(score) >= 80 then 0.1
else 0 end) as BONUS
from hr_employees e join hr_grade g
on e.emp_no = g.emp_no
group by e.emp_no, e.emp_name
order by e.emp_no;
```

## 실수 / 배운 점

- 조건이 애매하면 예시 출력으로 역산 (평균? 합계? 최신값?)
- 비율을 곱한 금액은 ROUND로 정수 처리
- SELECT의 일반 컬럼(SAL)은 GROUP BY에 넣거나, N쪽을 먼저 집계하고 JOIN

## 정리한 풀이

```sql
WITH g AS (
    SELECT EMP_NO, AVG(SCORE) AS avg_score
    FROM HR_GRADE GROUP BY EMP_NO
)
SELECT e.EMP_NO, e.EMP_NAME,
       CASE WHEN avg_score >= 96 THEN 'S'
            WHEN avg_score >= 90 THEN 'A'
            WHEN avg_score >= 80 THEN 'B' ELSE 'C' END AS GRADE,
       ROUND(e.SAL * CASE WHEN avg_score >= 96 THEN 0.2
                          WHEN avg_score >= 90 THEN 0.15
                          WHEN avg_score >= 80 THEN 0.1 ELSE 0 END) AS BONUS
FROM HR_EMPLOYEES e JOIN g ON e.EMP_NO = g.EMP_NO
ORDER BY e.EMP_NO;
```
