# 진료과별 총 예약 횟수 출력하기

`Lv.2` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/132202)

## 핵심 아이디어

2022년 5월 예약만 거르고 진료과별 COUNT.

## 내 풀이

```sql
SELECT mcdp_cd as '진료과코드', count(*) as '5월예약건수'
from appointment
where apnt_ymd >= '2022-05-01' and apnt_ymd < '2022-06-01'
group by mcdp_cd
order by count(*), mcdp_cd;
```

## 실수 / 배운 점

- ORDER BY `'별칭'`(작은따옴표)은 문자열 상수라 정렬이 안 된다(에러도 없음) → 집계식 그대로 쓰거나 `` `백틱` ``
- 따옴표: `'작은'` = 문자열 / `` `백틱` `` = 이름
