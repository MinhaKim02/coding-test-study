# 저자 별 카테고리 별 매출액 집계하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/144856)

## 핵심 아이디어

BOOK_SALES → BOOK → AUTHOR 3개 테이블 JOIN, 2022년 1월만 거른 뒤 저자·카테고리별로 SUM(판매량 × 가격).

## 내 풀이

```sql
with cte as (
select BOOK_ID, SALES_DATE, SALES
    from BOOK_SALES
    where SALES_DATE between '2022-01-01' and '2022-01-31'
)
SELECT author.AUTHOR_ID, author.AUTHOR_NAME, book.CATEGORY,
SUM(sales*price) as TOTAL_SALES
from cte join book on cte.book_id = book.book_id
join author on book.author_id = author.author_id
group by author_id, author_name, category
order by author_id, category desc;
```

## 실수 / 배운 점

- 두 테이블에 같은 이름 컬럼(AUTHOR_ID)이 있으면 GROUP BY에서 ambiguous 에러 가능 → `a.AUTHOR_ID`
- DATETIME이었다면 `BETWEEN … '2022-01-31'`은 31일 오후가 빠진다 → `>= '2022-01-01' AND < '2022-02-01'`
- WHERE 하나로 충분하면 CTE 없이 바로

## 정리한 풀이

```sql
SELECT a.AUTHOR_ID, a.AUTHOR_NAME, b.CATEGORY,
       SUM(s.SALES * b.PRICE) AS TOTAL_SALES
FROM BOOK_SALES s
JOIN BOOK b   ON s.BOOK_ID = b.BOOK_ID
JOIN AUTHOR a ON b.AUTHOR_ID = a.AUTHOR_ID
WHERE s.SALES_DATE >= '2022-01-01' AND s.SALES_DATE < '2022-02-01'
GROUP BY a.AUTHOR_ID, a.AUTHOR_NAME, b.CATEGORY
ORDER BY a.AUTHOR_ID, b.CATEGORY DESC;
```
