# 입양 시각 구하기(2)

`Lv.4` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/59413)

## 핵심 아이디어

0~23시를 모두 출력해야 해서 숫자 테이블이 필요하다. WITH RECURSIVE로 0~23을 만들고 LEFT JOIN 후 COUNT(오른쪽 컬럼).

## 내 풀이

```sql
with cte as
(select hour(time(datetime)) as hour, 1 as cnt from animal_outs),
recursive nums as (
select 0 as n
union all
select n + 1 from nums
where n < 23)
SELECT HOUR, sum(ifnull(cnt, 0)) as COUNT
from nums left join cte on nums.n = cte.hour
group by hour
order by hour;
```

## 실수 / 배운 점

- `RECURSIVE`는 WITH 바로 뒤에 한 번만 (`WITH RECURSIVE a AS (…), b AS (…)`)
- LEFT JOIN 결과의 SELECT/GROUP BY 기준은 왼쪽 테이블(nums.n)에서 — 오른쪽은 NULL일 수 있다
- COUNT(*)는 NULL 행도 1로 센다 → `COUNT(오른쪽.컬럼)`
- 재귀 CTE: 시작 부분 UNION ALL 반복 부분(+멈춤 조건). 매 바퀴는 직전에 새로 생긴 행만 읽는다

## 정리한 풀이

```sql
WITH RECURSIVE nums AS (
    SELECT 0 AS n
    UNION ALL
    SELECT n + 1 FROM nums WHERE n < 23
)
SELECT nums.n AS HOUR, COUNT(o.ANIMAL_ID) AS COUNT
FROM nums
LEFT JOIN ANIMAL_OUTS o ON nums.n = HOUR(o.DATETIME)
GROUP BY nums.n
ORDER BY nums.n;
```
