# 부서별 평균 연봉 조회하기

`Lv.4` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/284529)

## 핵심 아이디어

부서와 사원을 JOIN하고 부서별 AVG(SAL), 소수 첫째 자리에서 반올림.

## 내 풀이

```sql
select t1.dept_id DEPT_ID,
DEPT_NAME_EN,
round(avg(sal), 0) as AVG_SAL
from hr_department t1 join hr_employees t2
on t1.dept_id = t2.dept_id
group by t1.dept_id, dept_name_en
order by AVG_SAL desc;
```

## 실수 / 배운 점

- GROUP BY/HAVING은 FROM 컬럼을 먼저 찾는다 → 두 테이블에 같은 이름이 있으면 ambiguous 에러 (ORDER BY는 별칭 우선이라 통과)
- LEFT JOIN은 직원 없는 부서도 NULL로 남김 → '없는 것도 출력' 조건 없으면 INNER JOIN
- IFNULL은 문제에 'NULL은 ~로 취급'이 있을 때만
- ROUND(x) = ROUND(x, 0) / '첫째 자리에서' → 0, '첫째 자리까지' → 1
