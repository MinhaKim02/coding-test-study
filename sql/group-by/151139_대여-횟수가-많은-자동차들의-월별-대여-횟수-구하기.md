# 대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/151139)

## 핵심 아이디어

① 8~10월 '총' 5회 이상인 CAR_ID를 서브쿼리로 ② 그 차들의 월별 COUNT. 2단계.

## 내 풀이

```sql
SELECT month(start_date) as MONTH, CAR_ID, count(*) as RECORDS
from car_rental_company_rental_history
where car_id in (select car_id from car_rental_company_rental_history
                 where start_date >= '2022-08-01' and start_date < '2022-11-01'
                 group by car_id
                 having count(*) >= 5;)
group by car_id, month(start_date)
having count(*) > 0
order by month(start_date), car_id desc;
```

## 실수 / 배운 점

- 처음엔 `HAVING COUNT(*) >= 5`를 월별 그룹에 걸었음 → '기간 전체' 기준과 다름
- CTE 괄호는 `( )` (`{ }` ❌)
- 서브쿼리 안에 `;` ❌
- IN 서브쿼리는 '누구'만 거름 → 바깥 쿼리에도 기간 조건
- `HAVING COUNT(*) > 0`은 항상 참

## 정리한 풀이

```sql
SELECT MONTH(START_DATE) AS MONTH, CAR_ID, COUNT(*) AS RECORDS
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE START_DATE >= '2022-08-01' AND START_DATE < '2022-11-01'
  AND CAR_ID IN (SELECT CAR_ID FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
                 WHERE START_DATE >= '2022-08-01' AND START_DATE < '2022-11-01'
                 GROUP BY CAR_ID
                 HAVING COUNT(*) >= 5)
GROUP BY CAR_ID, MONTH(START_DATE)
ORDER BY MONTH, CAR_ID DESC;
```
