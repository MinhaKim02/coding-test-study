# 특정 조건을 만족하는 물고기별 수와 최대 길이 구하기

`Lv.3` · `GROUP BY` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/298519)

## 핵심 아이디어

10cm 이하는 NULL로 저장 → 평균을 낼 때만 NULL을 10으로 취급.

## 내 풀이

```sql
select count(*) as FISH_COUNT, max(ifnull(length, 0)) as MAX_LENGTH,
FISH_TYPE
from fish_info
group by fish_type
having avg(ifnull(length, 10)) >= 33
order by fish_type
```

## 실수 / 배운 점

- AVG(col)은 NULL을 빼고 계산. 'NULL은 X로 취급' 조건이 있을 때만 `AVG(IFNULL(col, X))`
- MAX는 원래 NULL을 무시
