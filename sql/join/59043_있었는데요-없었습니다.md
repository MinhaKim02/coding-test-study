# 있었는데요 없었습니다

`Lv.3` · `JOIN` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/59043)

## 핵심 아이디어

JOIN 후 입양일 < 보호 시작일인 것.

## 내 풀이

```sql
select t1.ANIMAL_ID ANIMAL_ID, t1.name NAME
from animal_ins t1 join animal_outs t2
on t1.animal_id = t2.animal_id
where t1.datetime > t2.datetime
order by t1.datetime;
```

## 실수 / 배운 점

- 두 테이블 날짜 비교 = JOIN 후 `WHERE A.날짜 > B.날짜` (같은 이름이라 별칭 필수)
