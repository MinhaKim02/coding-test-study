# 없어진 기록 찾기

`Lv.3` · `JOIN` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/59042)

## 핵심 아이디어

OUTS에는 있고 INS에는 없는 동물 = NOT IN 또는 LEFT JOIN + IS NULL.

## 내 풀이

```sql
SELECT ANIMAL_ID, NAME
from animal_outs
where animal_id not in (select animal_id from animal_ins)
order by animal_id;
```

## 실수 / 배운 점

- NOT IN 서브쿼리에 NULL이 하나라도 있으면 결과 0건 → NULL 가능하면 LEFT JOIN + IS NULL

## 정리한 풀이

```sql
SELECT o.ANIMAL_ID, o.NAME
FROM ANIMAL_OUTS o
LEFT JOIN ANIMAL_INS i ON o.ANIMAL_ID = i.ANIMAL_ID
WHERE i.ANIMAL_ID IS NULL
ORDER BY o.ANIMAL_ID;
```
