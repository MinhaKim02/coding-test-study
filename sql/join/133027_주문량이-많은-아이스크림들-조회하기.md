# 주문량이 많은 아이스크림들 조회하기

`Lv.4` · `JOIN` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/133027)

## 핵심 아이디어

JULY는 맛 하나에 여러 줄(1:N). 그대로 JOIN하면 상반기 값이 복제된다 → JULY를 먼저 맛별로 집계한 뒤 JOIN.

## 내 풀이

```sql
with cte as
(select flavor, sum(total_order) total_july from july group by flavor),
cte2 as
(select f.flavor as FLAVOR,
 f.total_order + cte.total_july as TOTAL_ORDER
from first_half f join cte on f.flavor = cte.flavor)
select FLAVOR from cte2
order by TOTAL_ORDER desc
limit 3;
```

## 실수 / 배운 점

- 외래 키: 'A의 X는 B의 X의 외래 키' = A→B 참조, B는 1줄 / A는 여러 줄 (1:N)
- INNER JOIN은 한쪽에만 있는 맛을 버린다 → 기준 테이블이 있으면 LEFT JOIN
- `NULL + 숫자 = NULL` → LEFT JOIN 후 계산은 `IFNULL(값, 0)`

## 정리한 풀이

```sql
WITH j AS (
    SELECT FLAVOR, SUM(TOTAL_ORDER) AS total_july
    FROM JULY GROUP BY FLAVOR
)
SELECT f.FLAVOR
FROM FIRST_HALF f
LEFT JOIN j ON f.FLAVOR = j.FLAVOR
ORDER BY f.TOTAL_ORDER + IFNULL(j.total_july, 0) DESC
LIMIT 3;
```
