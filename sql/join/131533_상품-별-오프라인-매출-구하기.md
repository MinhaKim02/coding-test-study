# 상품 별 오프라인 매출 구하기

`Lv.2` · `JOIN` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131533)

## 핵심 아이디어

상품 코드별 매출 = SUM(가격 × 판매량).

## 내 풀이

```sql
select PRODUCT_CODE,
t1.price * sum(t2.sales_amount) as SALES
from product t1 join offline_sale t2
on t1.product_id = t2.product_id
group by t1.PRODUCT_CODE
order by t1.price * sum(t2.sales_amount) desc, product_code;
```

## 실수 / 배운 점

- PRICE가 집계 밖에 있으면 GROUP BY 설정에 따라 에러 → 곱셈을 SUM 안에

## 정리한 풀이

```sql
SELECT p.PRODUCT_CODE, SUM(p.PRICE * s.SALES_AMOUNT) AS SALES
FROM PRODUCT p
JOIN OFFLINE_SALE s ON p.PRODUCT_ID = s.PRODUCT_ID
GROUP BY p.PRODUCT_CODE
ORDER BY SALES DESC, p.PRODUCT_CODE;
```
