# 부모의 형질을 모두 가지는 대장균 찾기

`Lv.2` · `JOIN` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/301647)

## 핵심 아이디어

같은 테이블을 자식(c)·부모(p)로 셀프 조인. GENOTYPE은 비트(이진수 각 자리 = 형질 하나)라서, 자식이 부모 형질을 모두 가지면 `(자식 & 부모) = 부모`.

## 내 풀이

```sql
select c.ID ID, c.GENOTYPE GENOTYPE, p.GENOTYPE PARENT_GENOTYPE
from ecoli_data p join ecoli_data c
on c.parent_id = p.id
where p.genotype = (p.genotype & c.genotype)
order by id;
```

## 실수 / 배운 점

첫 시도:

```sql
on p.parent_id = c.id          -- 부모·자식 방향 반대
where p.genotype = c.genotype  -- '모두 가진다'를 같다로 비교
```

- 셀프 조인 부모 찾기: `자식.PARENT_ID = 부모.ID`
- 비트 포함 관계: "A가 B를 모두 포함" = `(A & B) = B`, "하나라도 포함" = `(A & B) != 0`
- 예) 부모 5(101), 자식 7(111) → 7 & 5 = 5 → 포함 ✅ (`=` 비교면 7 ≠ 5로 빠짐)

## 정리한 풀이

```sql
SELECT c.ID, c.GENOTYPE, p.GENOTYPE AS PARENT_GENOTYPE
FROM ECOLI_DATA c
JOIN ECOLI_DATA p ON c.PARENT_ID = p.ID
WHERE (c.GENOTYPE & p.GENOTYPE) = p.GENOTYPE
ORDER BY c.ID;
```
