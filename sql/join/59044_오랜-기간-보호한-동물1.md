# 오랜 기간 보호한 동물(1)

`Lv.3` · `JOIN` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/59044)

## 핵심 아이디어

입양 기록이 없는 동물(LEFT JOIN + IS NULL) 중 보호 시작이 오래된 3마리.

## 내 풀이

```sql
select t1.name NAME, t1.datetime DATETIME
from animal_ins t1 left join animal_outs t2
on t1.animal_id = t2.animal_id
where t2.animal_id is null
order by t1.datetime
limit 3;
```
