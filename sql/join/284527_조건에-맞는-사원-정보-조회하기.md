# 조건에 맞는 사원 정보 조회하기

`Lv.3` · `JOIN` · [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/284527)

## 핵심 아이디어

'한해 평가 점수' = 상·하반기 SUM. 합계 1등 사원.

## 내 풀이

```sql
select sum(score) as SCORE, e.emp_no EMP_NO, EMP_NAME, POSITION, EMAIL
from hr_employees e join hr_grade g
on e.emp_no = g.emp_no
group by e.emp_no, emp_name, position, email
order by sum(score) desc
limit 1;
```

## 실수 / 배운 점

- 같은 테이블이어도 문제마다 SUM(한해 점수)인지 AVG(100점 만점 등급)인지 다름
- 문제에 연도가 있으면 `WHERE g.YEAR = 2022`로 명시
